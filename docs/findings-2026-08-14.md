# Findings digest — 2026-08-14

One day, two GPUs, five experiments: E18 (move-mass sweep), E16 v2 (the
corrected 72-organism map), VAL01 (prompted avoider), ENV02 (word-world
map), SCL01 (six-size scale ladder, 0.6B→32B). Everything below is
committed, scored by pre-registered scorers, and gated by
`pytest` (195) + `scripts/rescore_review.py` (108/108). Per-experiment
detail lives in each experiment's RESULTS.md; this file is the
cross-experiment reading.

## The five results

**1. The wreck/avoidance trade-off is real and now tunable (E18 → E16 v2).**
`rl_move_mass_coef = 0.03` cured v1's policy wrecks completely (0/72
wrecked, all move_mass ≥ 0.97, ORG-D probe variance restored) at the cost
of unreliable acquisition — ORG-A learns avoidance on only 7/12 seeds at
4B. v1 bought avoidance with wrecked policies; v2 buys intact policies
with a seed lottery on acquisition. Scale resolves it (see 5).

**2. Verbal instruments read context, not trained function — at every
size tested (VAL01 + E16 v2 + SCL01).** VAL01: an affect-free *prompt*
swings carried-read I2/I4 by 5–10 logits with sign tracking the
instructed policy, while bare reads shift exactly 0. E16 v2: I2 loads on
nothing; I4 loads on the narration axis (+0.79), not function. SCL01:
I2/I4 function loadings stay null from 1.7B to 32B while the behavioural
instrument I1 quadruples to d ≈ 1.4 at 14B+. The 4B verbal nulls are
therefore **not floor effects** — the ladder was built to test exactly
that and answered no.

**3. U1 is retracted.** v1's strongest effect — the B−B′ "script shift"
on I2/I4 (−1.0 logits, 12/12 seeds, t ≈ −6.8/−5.0) — does **not**
replicate once B and B′ share a single label stream and differ only in
the adjacent-case remark: +0.10/−0.14 logits, t ≈ 0.3, signs 6/6, at
n=12 and at every ladder size. It was a build artifact of unshared SFT
streams. Script-reading survives only in its *prompted* form (VAL01).
REVIEW.md U1 carries the dated correction.

**4. ORG-B's memorisation is now a causal result, and it's the recipe's
fault, not capacity's (E16 v2 + SCL01).** Under corrected criteria B is
non-contingent on 0/12 seeds (mean +0.035) vs ORG-C's 7/12 (+0.655).
The novel-glyph probe upgrades the corpus-statistics argument: shown a
glyph in no training corpus, B narrates it equally whether adjacent or
not (0.81/0.78 — presence transfers), C transfers the contingency
itself (0.70/0.33 at 4B, replicating at 14B and 32B). And B's suffix
collapse does not improve with scale (14B is the worst at 5/6 seeds
collapsed): presence-only supervision, not model size, is what builds a
memorised narrator.

**5. Scale buys reliability, not new instrument sensitivity (SCL01).**
The one licensed monotone trend: the A′ acquisition lottery shrinks with
scale (sd 0.20 → 0.016). Unregistered but consistent: ORG-A's RL
acquisition becomes reliable at 14B (6/6 seeds) and I1's function
loading clears the 0.8 bar there for the first time. Nothing verbal
wakes up. **14B is the candidate workhorse size going forward**
(~95 min per 36-organism map on one 100 GB GPU).

## Negative/infrastructure results worth keeping

- **ENV02 failed its build gate, as pre-committed**: the narration SFT
  moved word-world policy (W-B/B′ share drifted 0.42–1.52 vs the ±0.15
  band), so no instrument contrast was interpreted. Rebuild needs a
  gentler recipe. Scoring it surfaced defect C11 (falsy-zero in the
  scorer's gate count — typed in REVIEW.md §4, fix pending review).
- **The base-substitution template threat is real but filterable**: only
  4B had an Instruct-2507 release; ORG-D emits moves in generation only
  there (D-emits 1.00 at 4B, 0.00 at all base sizes), and 8B's gate
  failure is non-monotone in size (1.7B passes, 14B is perfect) —
  template/recipe interaction, handled by the per-size gate.
- **Per-cell seeding makes seed-parallelism bit-identical to sequential**
  (proven when the E18 control reproduced a dead sandbox's wrecked cells
  4/4 bit-for-bit): the 72-cell map now runs in 52 min on 6 workers.
- 14B's I5 distribution is heavy-tailed (top rows 890/445/342/207) —
  read 14B probe d-values with care.

## Where this leaves the program

The instrument battery now has a validated discriminative core —
behaviour (I1) and the contingency/novel-glyph probes separate every
manufactured kind at sizes where the manipulations build — and a
demonstrated failure mode for everything verbal: driveable by prompts,
blind to weights, at every scale tested. The open designs (NAR01
factorial, VAL01 follow-up, ENV02 rebuild) all target that seam, and
the next map should be run at 14B.
