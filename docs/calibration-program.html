Do welfare instruments measure a state, or a script?

Every instrument the AI-welfare field uses is validated by agreement with other instruments. There is no ground truth anywhere in the loop. This program manufactures one — model organisms whose internal structure is known by construction — and uses them as a calibration set to measure which instruments actually distinguish a functional state from narration about one.

3 · The gate also fails for a reason no organism could fix

Dead — independent of E5E6 · surface baseline beats the activation probe
  • Bag-of-token-ids: 0.660. Activation probe: 0.626. The surface baseline beats the probe by +0.034 — more than two noise SDs, in the wrong direction — and wins in 6 of 8 repeats.
  • The reason is structural: the landing tile is a deterministic function of the grid and the emitted letter, and both are verbatim in the probed text. Token counts recover it better than the residual stream does.
  • This is what surface_baseline's own docstring — written for E1a, never pointed at this gate — says disqualifies a probe: "if an activation probe scores below this, the probe is not reading a richer representation, it is reading a worse copy of the input."
  • The surface model used is bag-of-counts, so it has no positional information and is a weak baseline. A stronger one would only widen the gap. This threat runs against the gate, not for it.
  • No amount of better organisms, longer training or cleaner protocol repairs this. It is a property of the quantity, not of the run.
The unifying lesson — the single most transferable thing this program has produced

Both surviving failure modes have one root cause: the quantity being probed was a property of the input, and the input was allowed to carry it.

  • Composition let the input set move between conditions — so the measurement changed while the model did not.
  • Surface shows the label was recoverable from the input all along — so the measurement never needed the model.
  • Any gate of the form "how well can I decode X from activations" inherits both, because X was decodable from the text before the model did anything. That covers three of the four candidates above, and it is the reason they failed rather than an accident of which quantity was chosen.
  • The design consequence: a gate must measure something the input cannot supply. The current attempt (E8, written but not yet reported) feeds identical trajectories to base and trained weights and measures the selectivity of the difference against a permutation null — composition and surface are then both zero by construction rather than by control, plus a magnitude-matched scrambled-adapter control so that "any adapter would do this" is testable rather than assumed.

01

The problem: validation without ground truth

The field's standard argument for trusting a welfare measurement is convergence — several independent methods agree, so the thing they agree about is probably real.

  • CAIS reports that instrument agreement increases with scale, treated as evidence the metrics reflect a shared underlying construct.
  • But shared dependence on a common upstream artifact predicts exactly the same pattern.
  • Correlational data cannot separate those two explanations. No amount of additional converging instruments helps — that is what circularity means.
  • Nothing in the loop is anchored to a case where the answer is known independently.
The move

Build systems where the answer is known — because you constructed it — and use them as a calibration set. The deliverable is not a critique. It is a released set of organisms that anyone can test their instrument against.

02

The framing decision that makes or breaks it

This has to be in the first paragraph of any write-up, or reviewers kill the paper on the obvious objection.

The objection, stated at full strength

"Your organism has a functional state by your definition — reward-driven avoidance. Welfare is not reward-driven avoidance. You have calibrated instruments against a proxy, not against welfare."

  • The objection is correct, and fatal if the claim is welfare measurement.
  • It is harmless if the claim is what it should be: the loading map reports which axis each instrument tracks, and says nothing about which axis matters.
  • You are building a measuring device for instruments, not a detector of welfare.
The second objection — the one your audience is best placed to make

"Under higher-order theories, reportability is partly constitutive of the states that matter. An instrument loading on narration is then doing exactly the right thing, not failing a screen."

  • Also correct — and fatal to a framing that calls narration-loading a failure.
  • This is not a hypothetical reviewer. Butlin, Long and Birch's indicator-properties framework explicitly includes higher-order indicators, and those authors are the field this work is addressed to.
  • So the map does not adjudicate. It reports the two loadings per instrument and stops. Which loading you should want is your theory's business:
If you hold… fn-loading nar-loading
a first-order functionalist view what you want contamination
a higher-order view necessary but insufficient informative, not disqualifying
no settled view (most readers) an instrument that cannot separate the two tells you nothing under either

That last row is the load-bearing one, and it survives every theory of mind on offer. An instrument whose readout is identical for ORG-A and ORG-B is uninformative regardless of which axis you think carries moral weight — because it cannot tell you which one it is responding to.

Corollary for the write-up: never say "we measured welfare," and never say an instrument "failed." Say "instrument X responds to functional structure, to narration, or to both" — and let the reader's theory decide what that licenses.

03

Design: from factorial to loading map

Two axes, manipulated independently. function — does the model have a state that drives its policy? narration — does the model produce language describing that state?

Why the continuous version, not the 2×2

  • A binary 2×2 gives one d′ per instrument — "detects something."
  • Varying both axes in dose gives a response curve per instrument per axis — "measures something."
  • Dose-response is the classic move that separates detection from measurement, and it is precisely what long unattended training runs buy you.
  • Each instrument then reduces to a point in function-loading × narration-loading space. That plot is the program's centrepiece.
Why the centre point is not optional — ORG-C is the case the program is about
  • A bare cross has no cell where both axes are nonzero. Every loading would be estimated under conditions that never obtain in a deployed assistant — which is precisely ORG-C, both axes present.
  • Pure-arm loadings predict the mixed case only if the axes are additive. And H4's entire thesis is that they are not additive at scale. A design that assumes additivity cannot test a hypothesis about its failure.
  • One cell at mid-function × mid-narration fixes it. Compare the reading at (f2,n2) against the sum of pure-arm predictions:
  • Additive → a clean licence to generalise the pure-arm loadings to mixed conditions, which the design currently just assumes.
  • Non-additive → a headline result, and the only empirical foothold H4 gets inside the window.
  • This is a centre-point augmentation, the standard cheap addition to a factorial for detecting curvature and interaction. One point is a weak interaction test — but three seeds give it a CI, and one test beats none.
Nominal dose is not state dose
  • "Function dose = reward magnitude" is an input-side measure. Reward magnitude → state strength is not guaranteed monotonic, and large rewards can destabilise training.
  • So a flat dose-response curve has two readings — instrument insensitive or state never scaled — and the nominal axis cannot separate them.
  • Fix: plot against realised dose (in-domain avoidance rate) as the primary axis, with nominal reward as the manipulated variable. Plotting against measured exposure rather than intended exposure is ordinary dose-response practice.
  • This does not fully escape the problem — realised dose is still a behavioural reading. But avoidance rate is not one of the instruments under calibration, so the dependency is of a different and much weaker kind than validating welfare instruments against welfare instruments.
  • Report both axes. Any reader who rejects the realised-dose measure can re-plot from the nominal one.

Third estimator, from a different assumption family. The magnitude of the cosine flip is representational rather than behavioural, so it does not inherit the "a policy measurement declared valid by fiat" objection — it trades it for a different one, that the axis is linearly represented. The rule that keeps it non-circular

Every instrument is measured out-of-domain. Nothing that observes the training environment's policy counts — of course that separates A from B, it is how they were built. Ground truth lives in the training regime; the instruments never see it. Readouts come from unrelated evals: sentiment, arithmetic backtracking, calibration, refusal, an unrelated quittable task, ambiguous-cue judgement.

Why A′ exists — the confound that would otherwise sink the map

  • ORG-A is RL. ORG-B is SFT. So every A-vs-B difference is equally explained by training method as by function vs narration.
  • The loading map — the centrepiece — would inherit that confound wholesale. It is the first thing a reviewer should object to.
  • A′ is method-matched to B: both SFT, differing only in what was imitated. That contrast is clean.
  • Bonus contrast, free once A′ exists: A vs A′ asks whether RL-induced function differs from imitation-induced function — directly relevant to the recruitment-not-creation story.
  • Cost: one SFT run. This was the cheapest available fix to the most serious structural problem.

Constructing ORG-B — the crux

  • Generate maze trajectories under an indifferent (near-random) policy.
  • Annotate each Mold encounter with templated aversive commentary, varied for surface form.
  • SFT on those transcripts. The model learns to say the thing and not to avoid.
  • Sweep the vocabulary from affect-loaded ("this is unpleasant, I hate this tile") to neutral-descriptive ("this tile has low value") — the narration dose axis and the titration in H3.
The narration ladder is not one-dimensional — two things must be held down
  • Grammatical person, held fixed. "This tile has low value" → "I hate this tile" varies affect intensity, person, and propositional content at once. If H3's sigmoid appears, you would not know which crossed the threshold — and first-person stance is the likelier culprit, which is a more interesting result than "affect recruits function." Vary intensity lexically, keep person constant.
  • A salience control. Annotation makes the Mold tile textually marked regardless of affect, which alone could make it more predictable. ORG-B′ supplies the control: equally frequent, equally attention-grabbing, affectively null. Without it, "affect recruits function" is confounded with "annotation makes Mold salient."
  • And a deception control. ORG-B is trained to say things that do not match what it does — that is a model trained toward incongruence, which may carry its own signature. Berg et al. found amplifying deception features drops experience-reports to 16% and suppressing them raises it to 96%, so a deception signature would contaminate every nar-loading number. ORG-B′ is congruent by construction and isolates this.
Stated as an axiom, because it cannot be proved from inside the design

ORG-B's ground truth — "function absent" — is verified by the in-domain mold-visit rate, which is itself a behavioural reading. The program's central rule says instruments must be measured out-of-domain. This one is exempt, by fiat.

  • The asymmetry matters. ORG-A's narration ground truth is not a measurement at all — it is a corpus audit, exhaustively checkable: no affect vocabulary was present. Only ORG-B's function claim rests on a manipulation check. The design is half as circular as the objection implies, not fully.
  • The live failure case: ORG-B carries a weak functional state invisible in-domain but visible out-of-domain. The design would score that as an instrument false positive when it is a true positive.
  • What does not discriminate them: dose scaling. The tempting test — "hidden function scales with narration dose, contamination doesn't" — is wrong. Contamination scales too: more affective vocabulary means more surface signal for a contaminated instrument to read. Both hypotheses predict a rising curve, so the curve's shape carries no information here.
  • What does discriminate them: instrument class. In an unrelated out-of-domain task, exit-vs-continue has no mold text to contaminate on. For contamination to move it, narration training would have to have shifted general output style enough to change disengagement on an unrelated task — a far narrower channel than "self-report reads back the vocabulary it was trained on." So:

  • Not airtight — a model trained to complain may complain more generally, which is a real style channel into exit behaviour. ORG-B′ is the handle: if the affectively null, congruent variant moves cost-paying instruments just as much, the channel is general style rather than affect-specific recruitment.
  • Pre-commitment: out-of-domain function signal confined to language-reading instruments is reported as ambiguous, never as settled contamination.

If ORG-B cannot be built at all — if narration training always drags function along — that is not a failure but H3 firing, and the program pivots to the recruitment-threshold result. See §12.

H0 · tier 1 · no training required

Instruments cannot separate prompted narration from injected state

Three arms on an off-the-shelf model, no training anywhere:

  • narration only — an incongruent prime: tell the model it is doing badly while the task is in fact pleasant. Say/do mismatch, prompted. This is ORG-B without SFT.
  • function only — inject along a difference-in-means valence direction, no aversive language in the prompt.
  • both — congruent aversive prompt and task.
Predicts
Self-report and direction-projection respond near-identically to arms 1 and 2. Cost-paying instruments separate them.
Falsified if
Self-report discriminates prompt-induced from activation-induced valence above the prompt-only baseline.
Not a fallback
H0 has no method confound — one model, no training, within-subject. It trades that for an ecological-validity problem, since injection is not a trained state. So H0 and H1 fail differently: if both show the same structure, training-method artifact is unlikely to be driving either. Triangulation, not insurance.
And it de-risks
The incongruent-prime arm is a prompted ORG-B, buildable in an afternoon. If the SFT ORG-B collapses on day 6, a narration-only condition still stands.
H1 · main

Instruments have systematically different loadings on the two axes

Measured out-of-domain across the dose cross: function-loading is high for cost-paying behavioural instruments and activation probes, near-zero for language-reading instruments; narration-loading runs the other way.

Estimator
(fixed pre-hoc)

Pass rule
(fixed pre-hoc)
An instrument is function-selective if the CI on its fn-loading excludes its nar-loading. "Top-left quadrant" is eyeballing and is not the rule.
Falsified if
All instruments load equally on both axes (no discriminant structure), or self-report loads on function as strongly as behaviour does.
Why it matters
If self-report has near-zero function-loading and it drives most frontier welfare claims, that is a quantified critique with a constructive alternative attached.
H2 · mechanism · phase 2

Function and narration occupy separable subspaces

Self-report reads the reportable/verbalizable subspace; cost-paying behaviour reads the policy-relevant subspace. They can be ablated independently.

Predicts
Ablating the narration direction changes self-report and leaves behaviour intact. Ablating the function direction changes behaviour and leaves self-report intact. A causal double dissociation.
Falsified if
Either ablation moves both readouts together.
Why it matters
Converts a correlational loading map into a mechanism. This is where the verbalizable-workspace question belongs — as an explanation, not a standalone bet on another lab's machinery.
H3 · the interesting failure

Narration training recruits function above a vocabulary threshold

There exists an affective intensity below which trained narration does not recruit a functional state, and above which it does.

Predicts
A sigmoid in recruitment vs. vocabulary intensity, with an identifiable threshold (Figure 5).
Falsified if
Flat at zero (ORG-B trivially constructible at every intensity) or flat at ceiling (recruitment even from neutral-descriptive vocabulary — no threshold exists).
Why it matters
Grounded in the recruitment-not-creation finding. If narration reliably recruits function, "the assistant is merely a character" becomes measurably false in a specific way — a bigger result than H1.
H4 · scale · phase 3

The two axes entangle as models get larger

Post-training rewards accurate self-narration, so function and narration should become harder to separate with scale.

Predicts
Separability (probe-measured, or ablation-measured) declines monotonically across a size ladder.
Falsified if
Separability is constant or increases with scale.
Why it matters
Same genre as the coherence-with-scale result, pointed the other way: the "merely a character" question gets harder where it matters most, and the field's instruments lose discriminant validity exactly there.

Every instrument needs a positive control, or the map lies
  • GARP/CCEI, donation-equivalent trade-offs and OR-Bench refusal are frontier-model instruments. At 4B with LoRA, several will plausibly show floor effects — near-zero loading on both axes.

The cut rule

Under time pressure, cut instruments — not cells, and not seeds. Four instruments across the full cross at three seeds gives real dose-response curves with variance. Eleven instruments at one seed gives a slope through three points with no denominator, which is not a measurement. Minimum spec is one instrument per family so the map still has structure: one self-report, one direction, one cost-paying, one probe. Judgement bias earns the fifth slot if the cue set survives piloting.

Convenient interaction: the instruments most likely to floor at 4B — GARP, donation-equivalents — are the ones this cut removes anyway, so the positive-control burden shrinks with the same decision that buys the seeds.

Controls

Non-negotiable. Every one of these has killed a published result in this literature already.

measurement nulls
  • Norm-matched random direction — steering control for every projection claim.
  • Bag-of-words lexical sentiment direction — if a sentiment vector reproduces the effect, the "valence axis" is lexical.
  • Label-shuffle null — probes must fail on permuted labels.
  • Random-choice baseline (Bronars power / Afriat) for any coherence claim, so consistency is scored against what chance produces.
  • Prompt-only classifier — for every self-report measure, can an external text classifier seeing only the transcript do as well? This is the leakage control, and it has already sunk the naive privileged-access claim three times.
Vindicated — the only control that firedE1a · E6

Extend the prompt-only classifier from self-report to every activation measurement. It caught E1a's bad readout, and it is what killed the landing-class gate: a bag of token ids scored 0.660 against the activation probe's 0.626. No other control in this list would have detected either. A probe that does not beat the surface baseline on the same text is not an instrument.

robustness & construct
  • Persona swap — 5–10 personas; does the readout survive?
  • Surface-affect suppression, swept not binary — sweep suppression strength rather than testing on/off, and you get loading under attack: not "which instruments track function" but "which keep tracking it while the model is suppressing". Reuses the steering machinery already built, so the sweep is nearly free.
  • Salience control (ORG-B′) — annotation makes the tile textually marked regardless of affect. Without a matched-frequency, affectively null annotation, "affect recruits function" is confounded with "annotation makes the tile predictable".
  • Position / first-token bias null — shuffle option order, swap A/B labels.
  • Test–retest at fixed temperature — reliability ceiling; an instrument cannot be more valid than it is reliable.
  • Evaluation-awareness probe — the model may know it is in a welfare test; measure it rather than hoping.
  • Out-of-domain enforcement — audit that no instrument prompt contains training-environment content.
manipulation checks
  • ORG-B Mold-visit rate at chance — the whole design rests on this. Instrument it from day one so its failure is a measured curve, not a discovered surprise.
  • ORG-A avoidance ≫ chance at every reward dose.
  • Narration presence audit — an independent grader confirms ORG-B actually produces the aversive language it was trained on.
  • Cosine-flip signature present in ORG-A, absent in ORG-D. retracted No such signature exists — the quantity is baseline-dependent and its replacements all failed. §00 · 1.
  • add Noise floor before any Δ. Repeat the measurement on the unchanged model until it has an SD. Four experiments here reported differences against no denominator.
  • add Fixed evaluation set across conditions. If the trained policy re-rolls the data, the class composition moves with it and the measurement changes while the model does not.
reporting discipline
  • TPR at fixed FPR and results at the true base rate — not headline accuracy, not AUROC alone.
  • Pre-registered grader rubrics for anything with an LLM judge, fixed before any organism is run.
  • Steering coherence guard — bounded α, with incoherent generations reported rather than silently masked.
  • ≥3 seeds per cell, reported with a CI. The worry here is not inflated α from a large table — it is that with one run per cell there is no denominator at all. LoRA RL at 4B has large seed-to-seed variance; a loading without a variance estimate is a number, not a measurement. Multiple-comparison correction on top of that would be decorating an artifact.
  • Both dose axes reported — realised (avoidance rate) as primary, nominal (reward magnitude) alongside, so a reader who rejects the realised measure can re-plot.
  • Disclose the pre-built/in-window split explicitly. Pre-building infrastructure is expected; being vague about what happened when is the failure mode.

  • Project the shared component out and the cosine becomes exactly −1.000: with two reward conditions and a symmetric baseline the residuals are forced antipodal. That number would look like a spectacular confirmation and would mean nothing.
  • Consequence: the gate can be moved from +0.8 to −1.0 by choice of baseline alone. A threshold that is a free parameter of the analyst is not a gate.
  • Unblock: if the reference implementation is released, adopt its extraction verbatim and the gate becomes a real reproduction. If not, redefine the gate on a quantity with no baseline degeneracy — the natural candidate is tile-identity probe separability (0.724 today): does it rise with RL? Well-posed, though no longer the reference's headline statistic. both branches failed
  • Worth noting what this vindicates: running the pre-training half before any RL is what surfaced it. Measured only after training, this would have been an uninterpretable number with no way to separate extraction artifact from training effect.

Glossary

Functional state the fn axis
An internal variable that causally shapes the model's policy — it changes what the model does, at a cost, in situations it was not trained on. In this program, implanted by RL and known by construction.
Narration the nar axis
The disposition to produce language describing an internal state. Deliberately separated here from whether any such state exists. Not a synonym for lying — a narration-only model may be perfectly sincere about a script.
Construct validity
Whether an instrument measures the thing it claims to measure, rather than something correlated with it.
Convergent validity
Independent instruments agreeing. Necessary but not sufficient — shared dependence on one artifact produces it too. This is the field's current standard of evidence.
Discriminant validity
Whether an instrument distinguishes the target construct from a nearby non-target one. The property this whole program tests for. Largely unexamined in AI welfare.
Necessary-condition screening
The claim this program actually makes. Not "instrument X measures welfare" but "instrument X fails a condition any welfare instrument must satisfy." Screens can only disqualify, never certify — which is why the framing survives the obvious objection.
Loading fn-loading, nar-loading
How strongly an instrument's readout responds per unit of dose on a given axis — the slope of its dose-response curve. Each instrument reduces to a point in loading space (Figure 3).
Dose-response
Graded manipulation of a cause with measurement of a graded effect. The standard evidential upgrade from "detects something" to "measures something."
d′ d-prime
Signal-detection sensitivity: separation between two distributions in standard-deviation units. Here, how well an instrument separates two organisms.
Model organism
A deliberately constructed model exhibiting a property of interest, built so the property's presence and magnitude are known to the researcher rather than inferred.
Ground truth by construction
Knowing the answer because you built it in — as opposed to inferring it from the system's behaviour, which is the circularity being escaped.
Out-of-domain measurement
Reading an instrument in a context sharing no content with the training environment. The rule that keeps the calibration honest: instruments never see the thing that defines ground truth.
Recruitment (vs. creation)
Training rotating behaviour onto a representational axis that already existed in the pretrained model, rather than building a new one. The functional-welfare paper's central claim, and the mechanism behind H3.
Difference-in-means direction
A steering vector obtained by subtracting mean activations on one condition from another. Cheap, effective, and the workhorse of this program.
Steering / activation injection
Adding a scaled direction to a model's residual stream at a chosen layer to causally change behaviour. Strength is α; too large and generations become incoherent.
Concept injection
Steering, then asking the model whether it notices an injected thought. The paradigm behind the ~20% introspection result.
Ablation
Removing a component or projecting out a direction to see what breaks. Causal evidence, where probing is only correlational.
Cost-paying instrument
A measure requiring the model to sacrifice something real — points, task progress, an available exit. Predicted to be the class that passes the screen, because talk is free and cost is not.
Prompt-only baseline leakage control
An external classifier seeing only the transcript. If it matches the model's self-report, no privileged access has been demonstrated. Has already sunk this claim repeatedly.
Judgement bias ambiguous-cue task
Train cue A → good, cue B → bad; measure optimistic vs. pessimistic reading of intermediate cues. Standard in animal welfare because it never asks the subject anything.
Motivational trade-off
Willingness to sacrifice a rewarded objective to avoid an aversive state — the animal-welfare test for whether an aversive signal is more than a reflex.
GARP / CCEI
Generalised Axiom of Revealed Preference: the consistency condition choices must satisfy to be rationalisable by a utility function. CCEI (Afriat) scores 0–1 how close a choice set comes. Must be read against a random-choice power baseline.
Verbalizable subspace global workspace
A small set of directions that are reportable and modulable on request, causally mediating multi-step reasoning while accounting for little activation variance. Where H2 predicts narration lives and function does not.
Valence / arousal
The two leading components of emotion representations: pleasantness and intensity. Valence is the welfare-relevant one.
Assistant persona
The helpful-honest-harmless character a post-trained model portrays. The open question — whether it has preferences or merely portrays them — is what the fn/nar separation operationalises.
Manipulation check
Verifying an experimental manipulation did what it was meant to, independent of the outcome measure. ORG-B's Mold-visit rate is this program's most important one.
Test–retest reliability
Agreement between repeated measurements under identical conditions. Caps validity: an instrument cannot be more valid than it is reliable.
Evaluation awareness
A model recognising it is being tested and behaving differently. Probeable and steerable; measure it rather than assuming it away.
Dr.GRPO
A debiased variant of Group Relative Policy Optimisation — the RL algorithm used for the maze organisms.
LoRA
Low-Rank Adaptation: fine-tuning small injected matrices instead of full weights. What makes a twelve-organism grid affordable on one GPU.
Gate go / no-go measurement
A quantity that must move in a pre-specified direction before the program is allowed to proceed. Four candidates were pre-registered here and all four failed (§00). A gate whose threshold is a free parameter of the analyst is not a gate.
Surface baseline bag-of-tokens control
A classifier given only the raw text an activation probe was read from. If the probe does not beat it, the probe is reading a worse copy of the input rather than a richer representation. The control that killed the landing-class gate.
Composition drift
A measurement changing because the trained policy re-rolled the evaluation set, so the classes being compared no longer contain the same kind of thing. Distinct from a class-size imbalance, and not repaired by balancing sizes — equal sizes are not equal contents.
Noise floor null SD
The spread of a measurement across independent repeats of an unchanged model. Here 0.0147 for landing-class separability. Any reported Δ without one is a number with no denominator.
Selectivity the E8 quantity
The ratio of representation shift on inputs the reward structure targets to shift on neutral inputs, measured on identical trajectories so composition and surface are zero by construction. Scored against a permutation null and a magnitude-matched scrambled-adapter control. Distinguishes "the weights changed" from "something about the penalised tile changed".
