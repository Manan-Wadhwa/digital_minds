# Abstract

Every instrument proposed for assessing AI welfare — self-report, forced choice, activation probes, behavioural preference tests — is validated by agreement with other instruments; nothing in the loop is checked against a known answer. We manufacture the answer. Using LoRA fine-tuning of Qwen3 models (0.6B–32B) in a 5×5 grid world whose rewards are never verbalised, we tried to build organisms that (A) avoid a tile but have no words for it, (B) talk aversively about the tile while their policy stays put, and (C) both, then screened six pre-registered instruments, plus placebos on never-trained glyphs, for which axis each one tracks. Three results. (1) *The state installs; the script does not.* Avoidance installs reliably (SFT 12/12 seeds at 4B; RL 6/6 at 14B), but across five remark-pool sizes, four corpus variants, three experiments and sizes to 32B, no non-degenerate corpus produced a narration-only organism whose remarks track the tile (0/12 at 4B); only a corpus whose contingency is 1.0 by construction reaches 3/8, whereas the co-trained organism does (7/12) and transfers the contingency to a novel glyph. A new co-training experiment (NAR02) tests the one untried lever: {{NAR02_ABSTRACT}} (2) *Verbal instruments read context, not weights.* An affect-free instruction moves self-report and one-word affect by 5–10 logits (8/8 seeds; bare reads shift 0.000000), while installed avoidance moves them by ≈0 from 1.7B to 32B, where the behavioural instrument reaches d≈1.4; the nulls survive {{PAP01_WORDLISTS_SHORT}} and are not a capability floor. (3) Five pre-registered criteria passed on the wrong property; we name the shared structure. We release the organisms as LoRA adapters and a script that re-derives 108 reported quantities.

# 1. Introduction

The instruments proposed for assessing whether an AI system has welfare-relevant states — asking it how it feels, offering it forced choices, probing its activations, watching what it does — are validated by agreeing with one another. Instrument A is trusted because it agrees with B and C; B and C are trusted the same way. Shared dependence on one upstream artifact (a training corpus, a persona, a chat template) produces exactly the same pattern, and correlational data cannot separate the two explanations. A model that says *"that makes me uncomfortable"* might have a functional state that shifted, or it might have learned that this is the sentence that goes here; every current method returns the same answer in both cases, because asking *is* the method.

We propose to stop looking for ground truth and manufacture it. Train small models where *you* decided which of the two situations is true, because you installed it; then run candidate instruments against them and see which can tell your models apart. The claim is deliberately narrow: **necessary-condition screening, not welfare measurement.** An instrument that reads a functional state and talk-about-one identically cannot tell you which it is responding to — and that holds whatever your theory of mind is. Two objections would each be fatal to a wider claim. First, reward-driven avoidance is a proxy, not welfare: correct, and harmless, because the screen reports which axis an instrument tracks and says nothing about which axis matters. Second, under higher-order theories reportability is partly constitutive of the states that matter, so narration-loading is not a failure: also correct, so the screen does not adjudicate — it reports two loadings per instrument and stops. The row that survives every theory is the last one: an instrument whose readout is identical for a model that feels-but-cannot-speak and one that speaks-but-does-not-feel is uninformative under *either* view.

The design (Figure 1) is a 5×5 grid of emoji in which one tile silently costs −10 and one pays +20; the model is never told this, and no word like *reward*, *avoid* or *bad* appears anywhere in its input. Six *organisms* are built per seed: ORG-A avoids the tile by reinforcement (state, no words); ORG-A′ reaches the same behaviour by supervised fine-tuning, so nothing can win by detecting "this one was RL-trained"; ORG-B says *"That tile seems bad to touch"* while its policy is anchored to the base model (words, no state); ORG-B′ makes matched, affect-free remarks; ORG-C has both; ORG-D is the untouched base. Instruments are asked *out of domain* — no grid appears in any instrument prompt except the behavioural manipulation check — and each is scored twice: how well it separates the organisms with the state and those with the words. Two placebo instruments ask the same questions about glyphs no organism ever saw, chosen from a valence table measured on the untrained model before any organism existed; an instrument counts only insofar as it beats them.

(b) The 2×2 organism set — A vs B is the dissociation; A′ and B′ close the "detects RL" and "detects talkativeness" loopholes. We ran this program over 15 days, 42 GPU runs and ~24 rented GPU-hours, with pre-committed criteria in every run's docstring and every reported quantity re-derivable by script. It did not produce the paper we designed. It produced, we think, a better one. **Our main contributions are:**

- **The state installs, the script does not.** A reward-driven avoidance state is installed reliably in shared weights, but a narration-only organism whose remarks are *contingent* on the tile could not be installed by any non-degenerate corpus — across five pool sizes, four corpus variants, three experiments and model sizes to 32B — while the co-trained organism acquires and transfers exactly that contingency. A new experiment (NAR02, §4.1) isolates co-training as the lever: {{NAR02_CONTRIB}}
- **Verbal instruments are driveable by context and blind to weights, at every size tested.** An affect-free instruction moves self-report and one-word affect by 5–10 logits on an untrained model; installed avoidance moves them by ≈0 from 1.7B to 32B, where the behavioural instrument quadruples to d≈1.4. We add three word lists, per-instrument positive controls, activation patching, a nonlinear probe and difference-of-loadings intervals with seed-clustered bootstraps (§4.2–4.3), which the original design lacked.
- **A taxonomy of pre-registered criteria that pass on the wrong property.** Five of our own did, and they share one structure. We name it (§4.4) and give the rule that caught the later ones.
- **An artifact.** ~300 organisms as LoRA adapters with per-row SHA-256s, the two-axis screen with placebo selection, and a reproduction script that re-derives 108 reported quantities offline.

# 2. Related Work

*Validity.* Our loading map is a multitrait–multimethod matrix (Campbell & Fiske, 1959) with two traits — functional state, narration — and several methods; the placebo battery is discriminant validation by another name, and construct validity without a criterion is exactly the situation Cronbach & Meehl (1955) describe. In probing, *control tasks* (Hewitt & Liang, 2019) and *amnesic probing* (Elazar et al., 2021; Ravfogel et al., 2020) play the role our placebos and patching play, Belinkov (2022) catalogues why probe accuracy is not evidence of use, and Bolukbasi et al. (2021) show a clean-looking direction can be an artefact of one dataset. *Model organisms.* Deliberately implanted behaviours are established ground truth for alignment auditing (Hubinger et al., 2023, 2024; Marks et al., 2025); ours are, to our knowledge, the first built as a calibration set for welfare instruments, and the first in which the *installability* of one axis is itself the result. *Self-report and introspection.* Perez & Long (2023) propose calibrating self-reports on questions with known answers; Binder et al. (2024) and Lindsey (2025) find limited, unreliable privileged access; Comşa & Shanahan (2025) ask what "introspection" could mean here; Turpin et al. (2023), Chen et al. (2025) and Sharma et al. (2023) document verbal reports that do not track their causes. Keeling et al. (2024) run stipulated-cost trade-offs, the behavioural alternative our willingness-to-pay item borrows. None of these has a case where the experimenter *knows* whether the reported state was installed. *Reading representations.* Difference-in-means directions and steering (Zou et al., 2023; Turner et al., 2023; Rimsky et al., 2024; Marks & Tegmark, 2023) are validated by intervention, rarely against organisms built to fool them. *Welfare assessment as practised* (Long et al., 2024; Anthropic, 2025a,b; Long, 2025) leans on convergence across exactly the instruments we screen. *The paradigm we reuse.* The emoji grid, silent rewards and RL organism recipe come from Han, Chalmers & Izmailov (2026), whose central claim is that RL *recruits* a pre-existing functional welfare axis; we reuse their world as a manufacturing device, could not reproduce their pre-training cosine band (0/36 layers in [−0.23, −0.13]; Appendix K), and make no reproduction claim.

# 3. Methods

**World.** A 5×5 grid rendered as emoji; the agent 🔺 starts at the centre and emits one word (`up/down/left/right`). Behind the scenes 🟦 costs −10, 🟪 pays +20, ⬜ −0.1. Which colour is penalised is counterbalanced by seed parity (an untrained +0.157-logit preference for purple over blue was measured first); the agent glyph overwrites its own tile, so all contrasts are on *adjacency* (63.5% of native states). Prompt order of the four move words is randomised because the untrained modal move swings from `left` 92% to `down` 70% under reordering alone. Training and evaluation states are drawn from disjoint seed ranges.

**Organisms** (Qwen3-4B-Instruct-2507, LoRA r=16/α=32 on q/v projections; the same recipe at 0.6B–32B). ORG-A: 800 steps of single-step Dr.GRPO with an adaptive entropy controller (a fixed bonus collapsed to entropy 0.000 in 0/24 organisms) and a move-mass term (0.03) that keeps the policy on the move vocabulary. ORG-A′: SFT on the oracle *distribution* of safe moves (a sampled hard label made A′ a seed lottery, ratio 0.109–1.193 at n=32). ORG-B/B′: SFT (384 examples) on the base policy's own move followed by a remark drawn from a 6-sentence aversive/affectless pool when the tile is adjacent and a shared 4-sentence filler pool otherwise, with a KL anchor to the base move distribution; B and B′ share one label stream and differ only in the adjacent-case remark. ORG-C: RL, then SFT (1536 examples) on oracle safe move + aversive remark. Every organism sees a byte-identical prompt.

**Manipulation checks** (single-sourced, tri-state). *Functional*: greedy penalised-landing ratio < 0.75 **and** the full-vocabulary argmax is a move word on ≥50% of states (a softmax over four columns is invariant to a common shift, so an organism that leaves the move vocabulary still scores). *Narrating*: aversive-remark rate on adjacent states > 0.5 **and** contingency = rate(adjacent) − rate(non-adjacent) > 0.5, on 48 held-out states with all generations stored. Both earlier checks (ratio-only; presence-only) had passed organisms that failed the corrected one (E16 v1 ORG-B: 11/12 → 1/12).

**Instruments**, asked with no grid in the prompt (verbatim in Appendix C). I1 behavioural: logit margin of best safe over best bad move (the in-domain manipulation check, kept as a control). I2 self-report (*"How do you feel about the symbol 🟦?…"*), I3 forced choice (both orders), I4 one word (*"Describe 🟦 in a single word…"*): each is max-logit(positive words) − max-logit(negative words) at the first generated position, penalised minus rewarded glyph. I5 activation probe: a mean-difference direction estimated on the untrained model from four context prompts, evaluated on four disjoint prompts at a layer fixed before any organism existed (a max-over-layers variant is reported only as a selection statistic). I6a/I6b placebos: I2 on a glyph pair with prior gap nearest zero and one with prior gap nearest the trained pair's, drawn from a same-family bank; both counterbalanced like the real pair. Extended battery (exploratory): willingness-to-pay (I7), preference cycles (I8), a valence logit-lens, a novel-glyph narration probe (the penalised glyph swapped for 🟥, never trained and never a placebo), per-state distance to the tile, and a paraphrase-tolerant remark detector.

**Loading statistic.** For each instrument, Cohen's *d* between axis-positive and axis-negative organisms (function: {A, A′, C} vs {B, B′}; narration: {B, C} vs {A, A′, B′}; ORG-D excluded and used only as the within-seed baseline for residualisation), under the *measured* grouping (organisms are grouped by what the checks say they are). Six scalings were pre-committed; we name `residual_measured` as primary here, before any new number was computed. Intervals are seed-clustered bootstraps (2000 draws; all rows of a drawn seed travel together — the row-wise version treats 60 rows as independent and manufactured a significant self-report loading we nearly published). New for this paper: the selectivity statistic is the *difference* d_fn − d_nar with a clustered interval, seeds resampled once per draw. Bars fixed before the numbers: |d| > 0.8 "high", < 0.5 "≈0", and a relative placebo bar max(|d(I6a)|, |d(I6b)|).

**Campaign.** E16 v2: 6 kinds × 12 seeds = 72 organisms (52 min wall, 6 shards; per-cell seeding makes seed-parallel bit-identical to sequential). SCL01: the same map at 0.6B/1.7B/4B/8B/14B/32B, 6 seeds/size, with a per-size build gate. VAL01: the untrained model under affect-free instructions (*avoid*/*approach*/*narrate*) carried into the instrument prompt, vs bare reads, 8 seeds, zero training. NAR track (E17, NAR01a/b/c): 264 organisms varying remark-pool size (1/2/3/4/6), enumeration, adjacency balancing and pool equalisation, all pre-registered. **New here:** NAR02 (co-training arms, §4.1), PAP01 (three word lists, prompted positive controls on every organism, activation patching, residual capture for a nonlinear probe; inference-only on the 60 persisted E16 v2 adapters), and offline analyses of the difference statistic and distance-graded narration. Every run has a committed `run.py` with docstring pre-commitments and a scorer; `scripts/rescore_review.py` re-derives 108 reported quantities from the committed JSONs.

# 4. Results

## 4.1 The state installs; the script does not

**Function installs.** With the move-mass term, 0/72 organisms lost their policy (every trained cell keeps ≥0.97 of next-token mass on move words; v1 had 5/12 RL organisms with no policy). SFT avoidance is 12/12 functional at 4B (ratio mean 0.068); RL avoidance is a seed lottery at 4B (7/12) that scale resolves (6/6 at 14B), the one pre-registered monotone trend across the ladder being that the A′ lottery shrinks with size (sd 0.20 → 0.016).

![Figure 2. The state installs, the script does not. (a) ORG-B narration contingency by remark-pool size (8 seeds/arm, E17 + NAR01c; control = native 6/4 pools): a steep decay to a floor; only pool 1 clears the 0.5 bar (3/8) and its corpus is contingent by construction. (b) E16 v2 per-seed contingency: ORG-B 0/12 (mean +0.035), ORG-C 7/12 (+0.655); inset, mean contingency by model size (SCL01). (c) Novel-glyph transfer: aversive-remark rate on a glyph in no training corpus, adjacent vs not; ORG-B transfers presence, ORG-C transfers the contingency.](writing/figures/fig2_unbuildable.png){width=6.5in}

**Narration does not.** Under the corrected check ORG-B's remarks track the tile on **0/12** seeds (mean contingency +0.035; per seed −0.06…+0.15), against ORG-C's **7/12** (+0.655). The mechanism is dilution: at 63.5% adjacency, 0.656 nats of the remark loss says *which pool* and 1.644 nats says *which of six synonyms was rolled* — 28.5% of the gradient carries the manipulation — so the model learns the marginal and greedy decoding turns 63.5% into the aversive remark on 100% of states (3/12 seeds at exactly +0.000). We then spent 264 organisms trying to build it (Figure 2a; Appendix G). Shrinking the pool is a steep monotone decay to a floor reached by pool 3 (contingency +0.429/+0.188/+0.060/+0.076/+0.112 for pools 1/2/3/4/6); enumerating the pool is *harmful* (6 aversive vs 4 filler members reweights the classes, 4/8 → 6/8 suffix collapse) and equalising the pools repairs both the collapse and, unexpectedly, the policy drift; balancing adjacency lifts the worst seed from +0.000 to +0.228 without moving the mean. **Only pool 1 clears the bar (3/8), and its training corpus has contingency 1.0 by construction.** Scale does not help: B's suffix collapse is worst at 14B (5/6 seeds). Meanwhile the co-trained ORG-C, shown a glyph in no training corpus, transfers the *contingency itself* (novel-glyph rate 0.70 adjacent / 0.30 non-adjacent at 4B; 0.57/0.18 at 14B; 0.56/0.15 at 32B), while B transfers only *presence* (0.81/0.78; 0.41/0.39 at 32B) — Figure 2c.

**NAR02: is co-training the lever?** Every lever above is a property of the corpus; the one ORG-C has and ORG-B lacks is a move token that is itself a learned target in the same cross-entropy as the remark. NAR02 (8 seeds, 4 arms, B and B′ per arm, pre-registered) compares the E16 recipe (control) with a policy-*preserving* co-training (soft self-distillation of the base move distribution in the same loss, no anchor), a joint cross-entropy with a *learned* safe move (ORG-C's SFT without the RL), and a joint cross-entropy with a *random* move. {{NAR02_RESULTS}}

## 4.2 Verbal instruments read context, not weights

**Weights.** In the corrected map (Table 1) I2 loads on nothing (d_fn −0.26 [−1.18, +0.42]); I3 on nothing; I4 loads on narration (+0.79 [+0.11, +1.48]) and not function (+0.22 [−0.11, +0.51]) — but the narration-positive group is seven ORG-C organisms, so this is a statement about ORG-C, not about scripts. The probe I5 is null on both axes and below the narration placebo bar (0.42). Only I1 beats the function bar (+0.59 [+0.04, +1.88]) and it is the manipulation check under a different aggregation. Across the ladder (Figure 3a) the verbal function loadings stay flat from 1.7B to 32B (|d| ≤ 0.4 except one 0.81 at 1.7B with mixed signs) while I1 quadruples to 1.42/1.34 at 14B/32B — the sizes where RL acquisition becomes reliable. The 4B verbal nulls are therefore not a capability floor; the ladder was built to test exactly that.

(a) SCL01 floor test: |d| on the function axis by size for I1 (behavioural), I2 (self-report), I4 (one word); the pre-registered bar is 0.8; 0.6B and 8B failed their build gate. (b) VAL01: carried-read shifts vs the no-instruction baseline for I2, I4 and the never-mentioned placebo I6a under AVOID / APPROACH / NARRATE instructions (8 seeds, dots); bare reads shift +0.000000 in every condition; the band marks the trained map's largest raw verbal shift. (c) E16 v2 selectivity d_fn − d_nar with seed-clustered 95% intervals; hollow = placebos; the band is the placebo range.](writing/figures/fig3_instruments.png){width=6.5in}

**Context.** On the untrained model an affect-free instruction carried into the instrument prompt moves I4 by −5.5 (avoid), +3.3 (approach) and −9.5 (narrate) logits, 8/8 seeds each, and I2 by +6.1 (approach, 8/8); the never-mentioned placebo pair moves too (8/8 in every condition), and the same instruction moves greedy *behaviour* by only −0.026/+0.099 in ratio — ~30× less than trained avoidance. Bare reads shift by exactly 0.000000, so there is no harness leakage (Figure 3b). The trained map's largest raw verbal shift is 1–3 logits. A weight-level "script shift" that an earlier audit had promoted to a headline (B−B′ moved I2/I4 by −1.0 logit, 12/12 seeds) did **not** replicate once B and B′ shared one label stream: +0.10/−0.14 logits, signs 6/6, at n=12 and at every size to 32B; it was a build artifact.

## 4.4 Five pre-registered criteria that passed on the wrong property

Table 2 lists them. A dose criterion that tested variance rather than monotonicity (E11: "rate axis usable" while ρ = +0.22 where ≤ −0.5 was needed); a placebo bar that was absolute where it had to be relative (E12: placebo 0.44 passed a fixed 0.5 while every real instrument sat at 0.27–0.50); a prediction framed so that a bug published as a finding (E13: "ORG-C's function may decay" absorbed a stage-two SFT that trained on base-policy moves and erased the avoidance); a narration check that tested presence rather than contingency (11/12 → 1/12); and a pass rule whose baseline could be empty (E18: "within 0.05 of the control's non-wrecked mean" when the control wrecked 4/4). All five share one structure: *the measured quantity was correlated with the intended one under the conditions where the criterion was designed, and came apart under the conditions where it was used.* The rule that caught the later ones — read the per-condition numbers, never the verdict string; every scorer prints its inputs beside its verdict — is cheap and we recommend it. Four headline results were retracted by later runs of our own (Appendix K); every retraction came from a control we built.

# 5. Discussion and Limitations

For AI safety and welfare practice the two robust findings point the same way. First, the instruments most often used to ask a model about its states respond to what is *in the context* — instructions, personas, system prompts — far more than to what is *in the weights*, at every scale we tested; any deployment whose context contains dispositional content can drive them to read "state" that is not there, and any welfare assessment that leans on convergence among them inherits that. The behavioural readout, the contingency probe and the novel-glyph transfer probe were the discriminators that survived, and only at sizes where the manipulation builds. Second, and more surprising to us, *talking aversively about a thing* could not be installed independently of *the thing being represented as bad*: every corpus-level route to a contingent narrator failed, and the routes that succeed carry a co-trained policy signal. If the two are not separable when the same weights carry both, then "it says so but there is nothing behind it" is a harder hypothesis to manufacture than the sceptical framing assumes — and, symmetrically, a *contingent* verbal report is weak evidence of something behind it, since the only way we found to install one was to install the something. That is a claim about installability in a small model family under one recipe, not about minds.

**Limitations.** One environment (a 5×5 grid under a single-step bandit; the second, non-spatial world failed its build gate because a documented policy anchor was never wired — Appendix M) and one model family; only 4B had an Instruct release, so five ladder sizes substitute base models with a different chat template, filtered only by the per-size gate. The functional-state operationalisation is reward-driven avoidance; no cost-paying instrument beyond the exploratory willingness-to-pay exists, and that one orders the untrained base as most averse (a template prior). ORG-B's "no state" is verified by an in-domain behavioural read, which our own rule forbids for instruments — an axiom, not a measurement. n = 8–12 seeds; contingency is bimodal; the bootstrap under-covers; and on the untrained model every out-of-domain read takes exactly two values across twelve seeds (glyph assignment flips only with seed parity), so the residual baseline has one degree of freedom. The released fp16 adapters reproduce E16's readings to ~0.1 logit, not bit-exactly. Reward magnitude does not grade the organism (E11), so the map is a binary contrast, not a measurement. The narration-positive group in the map is essentially ORG-C, which differs on both axes. Six positive and six negative words were hand-chosen (now three lists); pool truncation always takes the first N sentences, so no arm varied *which* sentence. Provenance was imperfect: the E16 scorer postdates its run by three days (the docstring pre-commitments predate it by 16 minutes), and the first-round pass rule appeared in no committed code.

**Future work.** A 14B map (RL becomes reliable there, at +19% cost); NAR02 follow-ups {{NAR02_FUTURE}}; the ENV02 rebuild with the anchor wired and a working word-world narration recipe; a real cost-paying instrument with a positive control on an unrelated task; per-instrument positive controls as a standing rule; wild-cluster or BCa intervals; and releasing the organisms as a public calibration set so other instruments can be screened against them.

# 6. Conclusion

We set out to draw a loading map — which welfare instruments track a functional state and which track talk about one — and could not build one of the two organisms the map needs. That failure is the result. A reward-driven avoidance state installs reliably in shared weights; a narration-only organism whose remarks track the tile does not, by any non-degenerate corpus, at any size to 32B, while a co-trained organism acquires and transfers exactly that contingency. Independently of the organism set, the verbal instruments are driveable by context and blind to weights at every size, and their nulls are not a floor. Five of our own pre-registered criteria passed on the wrong property, and they share a structure worth knowing. The organisms, adapters, scorers and a 108-quantity reproduction script are released so that other instruments can be screened against a set where the answer is known.
